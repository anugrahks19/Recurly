# Assets inventory

No bitmap assets are copied into this workspace. The overlapping mint and ochre brand mark is built in CSS from the Stitch visual reference. The name displayed is Recurly, as required by the product brief.

External font requests are in `index.html`: Google Fonts for Playfair Display, Montserrat, and Material Symbols Outlined. For offline or locked-down hosting, self-host approved font files and update those links. The original Stitch screenshot and HTML are reference material and are not runtime dependencies.

Design values are recorded in `src/shared/styles/tokens.css`, derived from the Stitch screenshot and HTML palette. The main background is `#F7FAF8`, matching the screenshot. Responsive widths use 1220px, 900px, and 620px for this staff layout; align final application breakpoints during theme consolidation.
