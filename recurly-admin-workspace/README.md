# Recurrly Admin workspace

Developer 1's independent React workspace. The implemented design scope is the Admin dashboard at `/admin/dashboard`, based on the supplied Stitch subscription screen. Other Admin destinations expose read-only sample record views so navigation has a destination. They are not complete management modules.

Run `npm install`, then `npm run dev`. Run `npm run build` for a production bundle. See `integration/` for the transfer contract and sample-data limitations.
