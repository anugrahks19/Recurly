# Setup and verification

1. From `recurly-admin-workspace`, run `npm install`.
2. Run `npm run dev` and open `/admin/dashboard`.
3. Run `npm run build` before integration.

No environment variables are needed for the sample workspace. A future API base URL, shared auth context, and backend authorization are integration requirements. Test date range changes, ledger search/filter/sort/pagination, CSV export, record detail dialog, keyboard focus, compact navigation, and responsive layout after connecting real services.
